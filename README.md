# 🌀 奇门遁甲

> **三式之首，帝王之学。现在，你的Agent也会了。**

一句话提问，自动排盘+直断吉凶。时家奇门转盘法，八门九星八神全解。

---

## 🎯 一句话说明

问一个问题 → 自动起局排盘 → 告诉你成不成、该不该动、什么时候动手。

**不是给你一套理论让你自己悟，是直接断给你看。**

---

## 👑 为什么是奇门遁甲

古人打仗看它，帝王决策看它，谋士献策也看它。

不是迷信，是**时间空间决策模型**——把天时、地利、人和装进一个九宫格，让你一眼看清局势。

现在，轮到你了。

---

## 🔮 核心能力

- ✅ 时家奇门九宫完整排盘（地盘+天盘+人盘+神盘）
- ✅ 八门九星八神自动落宫
- ✅ 阳遁/阴遁十八局自动判断
- ✅ 吉凶格局智能识别（龙回首、鸟跌穴、天遁...）
- ✅ 用神自动匹配（20+场景）
- ✅ 直断吉凶，不绕弯

---

## 🛠️ 两种用法

### 作为Skill使用
装上SKILL.md，直接问问题。Agent自动排盘断局。

### 命令行使用
```bash
# 直接问
python qimen.py --question "我要创业能成吗"

# 指定时间起局
python qimen.py --time "2026-05-03 14:30"

# 保存结果
python qimen.py --question "今天出行顺利吗" --output result.md
```

零依赖，纯Python标准库。

## 🤔 FAQ

**这准吗？**
奇门遁甲是古代决策模型，不是水晶球。它提供的是一种结构化分析视角，帮你看到盲区。信不信由你，但用了总比干想强。

**和网上排盘工具有什么区别？**
那些只给你一张图。这个直接告诉你什么意思、该怎么做。

**需要学奇门遁甲吗？**
不需要。装上就问，问完就看结论。
